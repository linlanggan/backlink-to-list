# 📖 反链插入正文 (Backlink to Text)

帮助用户快速将当前文档的**反向链接（Backlinks）**提取到正文中。支持多种引用格式，支持自定义插入的内容格式。
---

## ✨ 核心功能


*   🔲 **双展示交互面板**：支持**气泡菜单**（悬挂于顶栏下方，轻量快捷）与**对话框**（居中大弹窗，视野开阔）两种展示模式，可在设置中随时切换。
*   📋 **多样化列表排版**：支持数字列表 (`1.`)、无序列表 (`•`)、任务列表 (`☑`)、引用块 (`▍`) 以及纯文本段落 (`¶`)。
*   🛠️ **高度自由的模板引擎**：支持通过 `${doc}`（反链文档）和 `${content}`（对应关联文本）标签自由组合单条反链的显示格式。
*   🔗 **灵活的引用表达方式**：
    *   文档与文本支持多种格式：纯文本、块引用 `((id "标题/文本"))`、超链接 `[标题](siyuan://...)`。
    *   可自主选择是否在对应文本中保留当前文档标题的字样。
*   🔄 **智能状态与防重同步**：
    *   自动勾选/过滤未插入的反链，已插入的反链会贴心标记。
    *   若手动删除了文档中已生成的反链块，插件会自动同步状态，允许再次插入。
*   🎯 **光标智能定位插入**：自动检测当前光标所在位置。
    *   若当前行**为空**，则直接在该行更新内容；
    *   若当前行**已有内容**，则在其**下方新建一行**插入反链列表；
    *   若未找到有效光标，则自动追加到文档末尾。

---

## 🚀 快速上手

1. **打开面板**：
   * 点击思源笔记右上角的插件顶栏图标。
   * 或使用快捷键命令：`整理反链列表（打开选择面板）`。
2. **选择反链**：
   * 在弹出的菜单或对话框中，系统会自动区分“未插入”与“已插入”的反链。
   * 支持快捷操作：`仅未插入`、`全选`、`全不选`、`反选`。
3. **确认插入**：
   * 勾选需要的反链条目，点击“插入选中项”，即可无缝沉淀到光标所在位置。

---

## ⚙️ 插件设置

右键点击顶栏图标或通过命令打开`反链整理插件设置`，您可以自定义以下偏好：

*   **基本渲染结构**：
    *   **面板展示模式**：气泡菜单 / 居中对话框
    *   **整体列表格式**：数字列表 / 无序列表 / 任务列表 / 引用块 / 纯文本段落
*   **单条反链格式模板**：
    *   提供可视化标签按钮（`${doc}`、`${content}`）以及常用预设快速套用。
*   **引用表达方式**：
    *   设置反链文档格式（纯文本 / 块引用 / 超链接）。
    *   设置对应文本格式（纯文本 / 块引用 / 超链接）。
    *   是否在正文中显示当前文档标题字样。
